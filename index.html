Welcome to Rumor

Developed by Darshan N Lal

Rumor is a lightweight 3D voxel sandbox game built to run smoothly directly in your browser without any installations or downloads.

Controls Guide

  • Desktop WASD to move | Space to jump
  • Mouse Click screen to lock camera & view around
  • Left Click Break Block | Right Click Place Block
  • Number 1-8 Switch Block Type
  • Mobile Left Virtual Joystick to move, Drag right screen to look, Use bottom buttons to Place/Break blocks.
